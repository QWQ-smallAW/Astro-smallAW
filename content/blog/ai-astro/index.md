## 为什么重做

用过 Hexo，它的主题 NexT，Yun 都用过，能用吗？当然，能用，但感觉自定义度还是太低了。

后来看到 Valaxy，看着挺不错就试了一下，也不错，但自定义度还是那样，最终的是被 pnpm 的 self-update 坑了。

烧心。

于是我让 AI 自己搭了个博客框架。这次只定了一条规矩：每一层都得是我自己能解释的。解释不了的不用。

## 选型：Astro，然后没有然后

内容型站点，Astro 基本不用纠结：Markdown 直出、默认零 JS、构建完就是一堆静态文件，扔 Cloudflare Pages 零配置。

第二个决定是不引 React/Vue，CSS 自己写。全部设计 token 压在 `:root` 里，暗色亮色各一套变量：

```css
:root {
  --bg: #0c1016;
  --accent: #4ade80;
}
[data-theme='light'] {
  --bg: #faf9f6;
  --accent: #177245;
}
```

好处很直接：依赖表短到 `npm audit` 一个告警都没有，主题切换就是换几个变量，也不用追组件库的更新日志。

代价是啥都得写。搜索、目录、灯箱、评论挂载……没有一个是从天上掉下来的。但反过来说，现在每一个像素为什么长这样，~~我~~ AI都答得上来。

AI 也都能修对。

## View Transitions，最大的坑

给页面加了切换动画（Astro 的 ClientRouter），然后开始连环翻车。

根源一句话：每次换页，DOM 整体替换。所以：

1. 挂在具体元素上的 `addEventListener`，换页即死
2. 模块顶层缓存的 DOM 引用，换页后全是尸体
3. 第三方库运行时注入的 `<style>`，一样被清掉

最后就剩三条保命规则：

```js
// 事件委托到 document，回调里实时查元素
document.addEventListener('click', (e) => {
  if (e.target.closest('#some-btn')) doSomething();
});

// 初始化逻辑挂 astro:page-load，换页后重跑
document.addEventListener('astro:page-load', init);

// 库自己注入的样式，换页前暂存、换页后放回
document.addEventListener('astro:before-swap', stashStyles);
document.addEventListener('astro:after-swap', restoreStyles);
```

第三条最阴。评论区“登录后刷新样式就乱”这个 bug，排查到最后发现是 twikoo 每次脚本加载只注入一次样式，而 View Transitions 换页把它清了。

## Twikoo 评论三进宫

评论组件前后折腾三轮：

- 第一轮，envId 用字符串插值传，结果 Astro 的 `<script>` 里花括号根本不插值，是字面量。改成 `data-*` 属性才对
- 第二轮，CDN 路径 404，新版脚本挪进了 `dist/` 子目录，顺便锁了版本
- 第三轮，前后端版本错位，登录后台样式全乱。前后端必须锁同一个版本号

每轮开场白都一样：“评论组件又炸了。”每轮结论也一样：锁版本，别追新。

## 安全

上线前做了一次全量审计，还真抓到自己一个洞。迷你终端里有个 `waifu` 命令，从第三方 API 拉二次元图片，返回的 URL 直接拼进 `src="${url}"`。哪天 API 被劫持，返回一个 `" onerror="恶意代码`，访客浏览器就替我执行了。

修复就两步：https 白名单，加属性转义。从此记住一句话：第三方 API 返回的每一个字节都是不可信输入，哪怕它只是一张图。

## AI 代开发

实际的工作流是这样：我描述需求或者贴报错，AI 出活，我跑 `dev` 和 `build` 验证，git 提交和推送永远自己按。整个过程里 AI 最值钱的时刻有两个——一是重复劳动，配置文件、响应式 CSS、事件委托的样板代码，它写得比我快十倍；二是排障，把报错原样丢过去，它经常能直接指出问题在哪。

但它翻车的方式也很有特色：

- 一本正经地写出不存在的 API 和版本号，语气跟真的一模一样

所以我的用法最后固定成一个模式：**让它写，但每个它写的东西我都得能解释**。解释得通才合入，解释不通就追问到懂为止——这恰好就是开头那条规矩。AI 能把活干完，但“知道网站为什么能跑”这件事，代不了。躺平当甲方是可行的，前提是你接受一个自己看不懂的网站，而我不接受。

顺带一提，这篇稿子 AI 也参与了，但坑全是真踩的。不然写不出“评论区又炸了”这种怨气。

## 彩蛋：博客得有点人味

框架写完之后，突然觉得页面太单调了，~~不符合我的气质~~。于是加了一层没什么用但很开心的东西：

- 按反引号或者点 logo 的 `$`，唤起一个迷你终端，能跑 `neofetch`，能随机抽看板娘
- 十一月自动飘雪，三月飘樱花
- 个人卡右下角一个「千万别点」按钮，点了整站变粉 5 秒

还挺好玩的就是。
